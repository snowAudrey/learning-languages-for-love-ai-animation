# Learning Languages for Love: AI Animation

**有用吗？ Is It Useful?** is a 66-second bilingual (Chinese/English) animation about why people learn languages, made from a short reflection I wrote for a student's writing project. I directed an AI agent (Claude, by Anthropic) through eight versions to get from that text to the final video.

**Watch it:** https://snowaudrey.github.io/learning-languages-for-love-ai-animation/

## My part
- Wrote the brief from my own text and teaching context.
- Reviewed eight versions and steered each revision: content, colour, lettering and music.
- Chose the final colours and Chinese typeface from rendered options.
- Had the English translations proofread and approved the corrections.
- Specified the learner-progress scene: pinyin, then a word, then sentences of growing difficulty.

## The AI's part
Claude wrote and ran all the code that drew the frames, synthesized the music and assembled the video (Python, NumPy, SciPy, Pillow, FFmpeg).

The original prompt is on the page.
